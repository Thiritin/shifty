# Contributing

Bug reports and pull requests are welcome. For anything larger than a fix, open an issue first so we can agree on the approach before you spend time on it.

[Development](docs/development.md) explains how to run Shifty locally and which checks CI runs. Keep pull requests to one change each, add a test when you change behaviour, and make sure Pint, ESLint, the type check and the test suite pass.

Shifty is MIT licensed, and so are contributions to it.
